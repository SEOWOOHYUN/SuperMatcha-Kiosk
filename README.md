# SUPER MATCHA KIOSK(소프트웨어공학 1조)

설계서를 바탕으로 만든 HTML/CSS/바닐라 JavaScript UI MVP

## 주문 흐름

먹고 가기 / 포장하기 → 6개 카테고리·28개 메뉴 → 메뉴별 옵션과 수량(1~10) → 장바구니 → 전화번호 적립 또는 건너뛰기 → 결제 → 주문번호.

- 첫 화면은 사진 없이 SUPER MATCHA 글자와 이용 방법 버튼만 표시합니다.
- 개인정보 동의 후 전화번호 입력·조회가 가능합니다. `010` 키는 빈 번호에만 접두어를 넣습니다.
- 결제 성공 시 결제액의 2%를 원 단위로 버림해 누적합니다. 5,800원 → 116원 적립.
- 카드 결제는 가상 승인입니다. 간편결제는 카카오페이 / 토스페이 / 네이버페이 선택 후 바코드 안내 화면에서 `스캔 완료 체험`으로 진행합니다.
- 결제 화면의 실패 체험 체크박스로 실패·재시도를 확인할 수 있습니다.
- 실패 시 주문·적립이 생성되지 않습니다. 중복 클릭은 차단합니다.
- 완료 화면에서 확인을 누르거나 10초가 지나면 장바구니·입력 번호를 지우고 첫 화면으로 돌아갑니다.
