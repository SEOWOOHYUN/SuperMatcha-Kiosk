# Kiosk Implementation Plan

> For agentic workers: use executing-plans task by task.

**Goal:** Implement the seven-screen UI MVP and commit on feature branches.
**Architecture:** Vanilla JS modules; view templates, controller events, isolated cart/payment/order/reward models.
**Tech Stack:** HTML, CSS, JavaScript, Node built-in test runner.
**Spec:** ../specs/2026-11-18-kiosk-design.md

## Global constraints
- Match supplied 9:16 UI, six categories, quantity 1–10; no runtime libraries.
- Payment is simulated; rewards are 2% rounded down, consent required.
- Feature branches only; preserve all work and never commit to main.

## Review focus
- Empty cart must not reach payment (cart/UI tests).
- Invalid option/quantity must not corrupt totals (cart tests).
- Repeated clicks must not duplicate order/reward (payment and checkout tests).
- Corrupt/unavailable storage must not silently reset balances (storage tests).
- Consent withdrawal/skip/reset must discard phone (browser checks).
